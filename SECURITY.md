# Security policy

## Supported versions

Antaeus has no released versions yet. This policy will list supported release lines before the first public release.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Use the repository's **Security** tab and choose **Report a vulnerability** to send a private report. Include the affected component or revision, reproduction steps, likely impact, and any suggested mitigation. Avoid including real credentials, customer data, or other sensitive material beyond what is necessary to understand the issue.

Maintainers will acknowledge a report, assess severity, coordinate a fix and disclosure timeline when warranted, and keep the reporter informed of material status changes. Response-time commitments will be published before supported releases are offered.

This channel is for vulnerabilities in the public Antaeus project. Security issues in a hosted Antaeus service should use that service's published reporting process once it exists.
